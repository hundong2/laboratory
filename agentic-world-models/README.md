이 자료는 원문의 큰 흐름을 따라 에이전트 강화학습(RL)에 세계 모델링을 결합하는 방법을 설명한다. 원문이 해설하는 ECHO, True Agents Model the World, PaW, Qwen-AgentWorld의 공개 자료도 교차 확인했다. 수치와 결론은 각 저자가 보고한 결과이며 독립 재현을 뜻하지 않는다.

## 한눈에 보기

일반적인 에이전트 RL은 한 궤적이 성공했는지에 대한 희소한 결과 보상으로 에이전트가 생성한 행동 토큰을 학습한다. 그런데 궤적에는 각 행동 뒤에 터미널 출력, API 응답, 화면 변화 같은 환경 관찰이 이미 들어 있다. 에이전트형 세계 모델링은 이 관찰을 다음 상태의 정답으로 보고, 에이전트가 자신의 행동 결과를 예측하도록 지도학습 신호를 추가한다.

핵심 아이디어는 다음 식으로 요약할 수 있다.

```text
전체 손실 = 정책 손실(RL, 행동 토큰) + λ × 세계 모델 손실(지도학습, 관찰 토큰)
```

RL은 “보상을 높이려면 무엇을 해야 하는가?”를, 세계 모델링은 “이 행동을 하면 환경이 어떻게 반응하는가?”를 가르친다. 두 목표는 대체 관계가 아니라 상호 보완 관계다.

## 기초 개념

### 에이전트 궤적

에이전트가 환경과 상호작용한 순서 기록이다.

```text
관찰 o₀ → 행동 a₀ → 관찰 o₁ → 행동 a₁ → 관찰 o₂ → ... → 보상 r
```

터미널 에이전트라면 행동은 shell 명령이고 관찰은 stdout, stderr, 종료 코드와 파일 변화다. GUI 에이전트라면 행동은 클릭·입력이고 관찰은 화면 상태다.

### 지도 미세조정(SFT)

정답 토큰을 다음 토큰 예측의 표적으로 사용해 cross-entropy를 최소화한다. 프리트레이닝과 SFT는 같은 기본 목적함수를 사용하지만 데이터 규모와 목적이 다르다. 에이전트형 세계 모델에서는 실제 궤적에 이미 존재하는 관찰 토큰이 정답 역할을 한다.

### 강화학습과 GRPO

강화학습은 모델이 생성한 행동의 보상을 이용해 정책을 갱신한다. GRPO는 같은 문제에 대한 여러 출력을 그룹으로 비교해 상대적 advantage를 만들고, 중요도 비율과 clipping을 이용해 지나친 정책 변화를 막는다. 결과 보상만 사용하면 실패한 긴 궤적의 어느 단계가 유용했는지 알기 어렵다.

### 토큰 마스킹

표준 에이전트 RL에서는 사용자 프롬프트와 환경 관찰 토큰을 손실에서 제외하고 모델이 생성한 행동 토큰에만 정책 손실을 적용한다. 세계 모델링은 관찰 토큰을 무시하지 않고 별도 cross-entropy 손실의 대상으로 삼는다. 같은 궤적이라도 토큰 역할에 따라 서로 다른 목적함수를 적용하는 것이다.

### 세계 모델

현재 관찰과 행동을 바탕으로 다음 환경 상태 또는 관찰을 예측하는 모델이다. 물리 세계를 영상으로 시뮬레이션하는 모델만을 뜻하지 않는다. 언어 에이전트에서는 API 결과, 터미널 출력, 검색 결과 또는 UI 상태를 텍스트나 렌더링 가능한 코드로 예측할 수 있다.

## 핵심 요약

1. 에이전트 궤적의 관찰은 행동 결과를 보여주는 조밀한 on-policy 감독 신호다.
2. ECHO와 PaW는 하나의 정책 모델에 RL 행동 손실과 관찰 예측 손실을 함께 적용한다.
3. 관찰 예측만 학습하면 좋은 시뮬레이터가 될 수 있어도 보상을 최대화하는 에이전트 행동은 악화될 수 있다.
4. 모든 관찰이 유용하지는 않다. 반복 오류, 무변화, 정답을 단순 복사하는 출력과 암기하기 쉬운 검색 결과는 필터링하거나 낮게 가중해야 한다.
5. Qwen-AgentWorld는 정책 안의 보조 손실 대신 별도 언어 세계 모델을 학습해 실제 환경을 대신하는 SimRL도 탐구한다.
6. 세계 모델이 틀리면 정책이 잘못된 가상 환경을 공략할 수 있으므로 실제 환경 평가와 simulator fidelity 검증이 필수다.

## 상세 정리

### 왜 결과 보상만으로 부족한가

성공 여부가 마지막에 한 번만 주어지면 수십 단계 중 어떤 행동이 원인이었는지 신용 할당이 어렵다. 성공하지 못한 궤적도 “명령을 실행했더니 어떤 오류가 났다”는 유용한 인과 정보를 갖지만, 순수 정책 그래디언트에서는 advantage가 작아 거의 학습되지 않을 수 있다.

환경 관찰 예측은 매 상호작용 단계에서 정답을 제공한다. 실패한 행동도 결과가 관찰되기 때문에 환경 역학을 배우는 데이터가 된다. 별도 rollout 없이 이미 수집한 궤적을 재사용할 수 있다는 점이 실용적이다.

### ECHO

ECHO(Environment Cross-entropy Hybrid Objective)는 행동 토큰에는 GRPO 정책 손실을, 환경 관찰 토큰에는 cross-entropy 손실을 적용한다. 원 논문은 같은 forward pass와 rollout을 재사용해 추가 환경 상호작용 없이 조밀한 학습 신호를 얻는다고 설명한다.

논문 보고에 따르면 TerminalBench-2.0 pass@1에서 Qwen3-8B는 2.70%에서 5.17%, Qwen3-14B는 5.17%에서 10.79%로 개선됐다. 해설 글은 8B 모델이 순수 GRPO의 최고 성능에 1.5~2.3배 적은 학습 단계로 도달하고, timeout과 생성 토큰도 줄었다고 요약한다. 절대 성공률은 여전히 낮으므로 “두 배”라는 상대 개선과 실제 해결률을 함께 봐야 한다.

### True Agents Model the World

Prime Intellect의 분석은 ECHO와 같은 방법을 여러 환경에 적용해 어떤 관찰을 학습해야 하는지 살핀다. 코드 실행 결과만 세계 모델 목표에 포함하고 문서 검색 결과를 제외한 설정이 `forth-lang`에서 더 좋았다는 결과는, 검색 문서를 그대로 예측하는 목표가 환경 역학보다 지식 암기를 유도할 수 있음을 보여준다.

세계 모델링은 훈련 도메인에서 대체로 도움이 됐지만 다른 도메인으로의 일반화는 행동 패턴에 따라 달랐다. 문서 검색 습관이 필요한 환경에는 전이됐지만 여러 도구를 복합적으로 사용해야 하는 일반 에이전트 환경에서는 성능이 낮아지기도 했다. 순수 세계 모델 학습에서 과제 성능이 저하된 결과도 있어 RL 손실을 0으로 만들지 말 것을 제안한다.

### PaW

PaW(Policy and World Modeling Co-Training)는 동일 정책 안에서 관찰 예측을 보조 목표로 사용한다는 점에서 ECHO와 유사하다. 차이는 보조 신호를 더 안정적으로 선택·가중하는 데 있다.

- 행동 entropy를 이용한 세계 모델 데이터 선택
- 잡음에 강한 세계 모델 손실
- reward에 따라 변하는 보조 손실 가중치

모든 관찰을 같은 가치로 학습하지 않고, 정책 학습 상태와 관찰의 정보량을 고려한다. 추가 환경 상호작용, 별도 모델 또는 추론 시 추가 계산 없이 훈련 절차만 바꾸는 것이 목표다.

### Qwen-AgentWorld

Qwen-AgentWorld는 MCP, 검색, 터미널, SWE, 웹, 운영체제, Android의 일곱 환경을 텍스트 기반으로 시뮬레이션하는 별도 언어 세계 모델을 학습한다. GUI도 렌더링 가능한 코드로 표현해 행동 이후 관찰을 텍스트로 예측한다.

훈련은 세 단계로 설명된다.

1. **CPT**: 환경 궤적과 전문 지식 말뭉치로 일반 역학과 세계 지식을 학습한다.
2. **SFT**: 다음 관찰을 예측하기 전 reasoning trace를 생성하는 능력을 활성화한다.
3. **RL**: 규칙과 rubric 보상으로 시뮬레이션 충실도를 높인다.

전용 simulator를 정책과 분리하면 실제 환경 대신 대규모 가상 rollout을 만들 수 있다. SimRL은 정책 행동에 세계 모델이 관찰을 반환한다. API 오류나 페이지네이션 같은 부분 실패를 control instruction으로 주입해야 실질적인 정책 개선이 나타났다는 보고는, 매끄러운 성공만 흉내 내는 simulator가 충분하지 않음을 시사한다.

### 통합형과 분리형 비교

| 구분 | 통합형(ECHO, PaW) | 분리형(Qwen-AgentWorld/SimRL) |
| --- | --- | --- |
| 모델 | 정책 하나가 행동과 관찰을 학습 | 정책과 simulator를 분리 |
| 훈련 비용 | 기존 rollout과 forward pass 재사용 | 세계 모델 자체 학습 비용 필요 |
| 추론 | 일반 에이전트와 동일 | 훈련 또는 계획 시 simulator 호출 가능 |
| 장점 | 단순하고 on-policy 신호가 직접적 | 환경 인프라 대체, 통제된 실패 생성 |
| 주요 위험 | 보조 손실 과가중, 관찰 암기 | simulator 편향과 model exploitation |

## 수식으로 이해하기

궤적 토큰 `x`에 대해 행동 마스크 `m_action`과 관찰 마스크 `m_obs`를 둔다.

```text
L_policy = -Σ m_action(t) · A · log πθ(x_t | x_<t)
L_world  = -Σ m_obs(t) · log πθ(x_t | x_<t)
L_total  = normalize(L_policy) + λ · normalize(L_world)
```

실제 GRPO는 중요도 비율, clipping과 KL 항을 포함할 수 있다. 중요한 점은 정책 손실과 세계 모델 손실이 서로 다른 토큰에 적용되고, 규모를 별도로 정규화한 뒤 `λ`로 균형을 맞춘다는 것이다.

## 설계와 평가 체크리스트

### 데이터

- 행동과 관찰의 경계, 도구 이름, 종료 코드와 상태 변화가 정확히 기록되는가?
- 반복 오류, 빈 응답, 시스템 장애와 행동을 그대로 반향하는 관찰을 제거하는가?
- 테스트 verifier가 rollout 중 에이전트에 노출되지 않는가?
- 긴 prefix를 공유하는 표본을 같은 batch에 과도하게 넣어 다양성이 붕괴하지 않는가?

### 손실

- 정책과 세계 모델 손실을 토큰 수나 유효 샘플 수로 별도 정규화하는가?
- `λ` 변화에 대한 어블레이션과 early stopping 기준이 있는가?
- 검색 결과처럼 암기 위험이 큰 도구를 선택적으로 제외했는가?

### 평가

- 훈련 보상뿐 아니라 held-out 과제 성공률과 관찰 perplexity를 함께 보는가?
- in-domain과 다른 도구 구성을 가진 out-of-domain 환경을 분리하는가?
- 성공률, 단계 수, timeout, 토큰 수와 도구 오류를 함께 기록하는가?
- simulator를 쓰면 실제 환경과의 전이 격차와 부분 실패 충실도를 측정하는가?

## 용어 정리

| 용어 | 설명 |
| --- | --- |
| Policy | 관찰과 이력에서 다음 행동의 분포를 만드는 모델 |
| World model | 행동이 환경에 미칠 다음 상태·관찰을 예측하는 모델 |
| Trajectory | 관찰, 행동, 보상으로 이루어진 상호작용 기록 |
| On-policy | 현재 정책이 직접 만든 데이터로 학습하는 방식 |
| Outcome reward | 전체 궤적 성공 여부에 주로 기반한 결과 보상 |
| Process reward | 중간 단계별 품질을 평가하는 보상 |
| Cross-entropy | 정답 토큰의 예측 확률을 높이는 지도학습 손실 |
| Action masking | 정책 손실을 에이전트 생성 행동 토큰에만 적용하는 처리 |
| Observation masking | 관찰 토큰을 선택적으로 세계 모델 손실에 포함하는 처리 |
| Simulator fidelity | 가상 환경의 응답이 실제 환경 역학과 일치하는 정도 |
| Reward hacking | 평가 규칙의 허점을 이용해 실제 목표 없이 보상만 얻는 현상 |

## 확인이 필요한 사항

- 이 분야의 주요 결과는 2026년 공개된 최신 연구로, 장기간·다기관 재현 결과가 아직 제한적이다.
