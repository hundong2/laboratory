## 한눈에 보기

추측 디코딩(speculative decoding)은 작은 초안 모델 $q$가 한 번에 $\gamma$개 후보 토큰을 만들고, 큰 목표 모델 $p$가 이 후보들과 한 개의 다음 위치를 병렬 검증하는 방법이다. 단순히 후보를 채택하는 것이 아니라 확률비와 잔차 분포를 사용해 보정하므로, 구현이 정확하면 목표 모델을 순차 샘플링한 것과 같은 출력 분포를 유지한다.

지연 시간은 줄지만 총 연산량은 보통 늘어난다. 따라서 큰 모델의 한 번 호출에 여유 병렬성이 있고 작은 모델 비용 비율 $c$가 충분히 낮을 때 유리하다.

## 연구 질문과 기여

연구 질문은 “모델을 재학습하거나 구조를 바꾸지 않고, 자기회귀 Transformer의 메모리 대역폭 병목을 추가 병렬 연산으로 교환할 수 있는가?”다.

핵심 기여는 다음과 같다.

1. 초안 모델의 후보를 목표 모델 분포와 정확히 일치하도록 승인·거절하는 알고리즘을 제시한다.
2. 평균 승인률 $\alpha$, 초안 길이 $\gamma$, 비용 비율 $c$로 예상 처리량을 설명하는 분석식을 제공한다.
3. T5-XXL을 대상으로 번역과 요약에서 2~3배대 wall-clock 가속을 보이면서 출력 분포 동일성을 실험적으로 점검한다.

## 방법

### 승인과 잔차 보정

초안 토큰 $x_i$는 확률

$$
\min\left(1,\frac{p_i(x_i)}{q_i(x_i)}\right)
$$

로 승인된다. 첫 거절 위치에서는 $[p_i(x)-q_i(x)]_+$를 정규화한 잔차 분포에서 다시 샘플링한다. 모든 후보가 승인되면 목표 모델이 동시에 계산한 한 토큰을 추가한다. 이 보정이 빠지면 결과는 작은 모델 쪽으로 편향되며 “정확한” 추측 디코딩이 아니다.

평균 승인률을 $\alpha$라 할 때 목표 모델 호출 한 번에 생성되는 기대 토큰 수는

$$
\frac{1-\alpha^{\gamma+1}}{1-\alpha}
$$

이고, 이상화한 속도 비는

$$
\frac{1-\alpha^{\gamma+1}}{(1-\alpha)(\gamma c+1)}
$$

이다. $\gamma$를 크게 하면 더 많은 토큰을 승인할 기회와 더 비싼 초안 계산이 동시에 늘어난다.

### 분포 동일성의 의미

동일성은 같은 난수 시드에서 문자열이 항상 같다는 뜻이 아니라, 충분히 반복했을 때 목표 모델 샘플러의 확률 분포와 같다는 뜻이다. greedy decoding에서는 결정적 일치가 가능하지만, temperature sampling에서는 통계적 비교가 필요하다.

## 데이터·평가와 수치 결과

- 목표 모델: T5-XXL 11B
- 초안 후보: T5-small 77M 등이 비교되었고 77M 모델이 좋은 비용·품질 절충을 보였다.
- 작업: WMT English→German 번역, CNN/DailyMail 요약
- 환경: 단일 TPU v4, batch size 1
- 측정: wall-clock 지연 시간과 출력 점수·분포 보존

보고된 가속은 WMT에서 temperature 0일 때 3.4배, temperature 1일 때 2.6배이고, CNN/DailyMail에서 각각 3.1배와 2.3배다. 저자들이 측정한 $c$는 0.05보다 작고 많은 경우 거의 0에 가까웠다. 이 수치는 해당 모델·장치·배치 조건의 결과이며 GPU나 큰 배치로 그대로 이전할 수 없다.

## 한계와 재현 주의점

- 지연 시간을 줄이기 위해 더 많은 산술 연산을 사용한다. 유휴 병렬 자원이 없으면 손해가 될 수 있다.
- 고정 초안 모델과 고정 $\gamma$가 주제·문맥·길이에 따라 최적이 아닐 수 있다.
- 논문 실험은 텍스트 Transformer와 batch 1 중심이다. OCR의 긴 시각 prefix와 이미지 encoder 비용은 포함하지 않는다.
- residual distribution에서 모든 질량이 수치상 0이 되는 경계, EOS, temperature·top-k·top-p 순서, 캐시 위치를 엄밀히 맞춰야 한다.
- 노트북은 작은 이산 분포와 toy Markov 모델을 사용하는 개념 재현이며 T5-XXL 결과를 재현하지 않는다.

## Trillion Labs 블로그와의 관계

[Diffusion으로 OCR 디코딩 가속하기](https://blog.trillionlabs.co/posts/diffusion-ocr/)에서 여러 후보 토큰을 제안하고 큰 모델 계산으로 검증한다는 생각은 추측 디코딩의 계보에 있다. 다만 원 논문은 별도의 작은 T5 초안 모델을 쓰고 확률적 잔차 보정으로 목표 분포의 정확한 보존을 증명한다. 블로그는 변환된 OCR 모델의 자기 추측(self-speculation), confidence 기반 병렬 복원, crop 단위 처리량을 다루므로 초안 생성기·검증 단위·시스템 병목이 다르다.

블로그의 decode-only 3.85배와 end-to-end 1.85배 차이는 원 논문의 핵심 시스템 교훈과 맞닿는다. 디코더를 크게 가속해도 vision encoder, 전처리와 I/O가 남으면 전체 가속은 작아진다. 블로그의 휴리스틱 confidence 채택을 이 논문의 “정확한 분포 보존” 보장과 동일시해서는 안 된다.
