# 패줌 (패스트 줌) - FPS 반응속도 게임

마우스 클릭 반응 속도와 정확도를 측정하는 HTML5 기반 FPS 게임입니다.

## 🎮 게임 특징

- **총 10라운드**: 각 라운드마다 60초 제한시간
- **스나이퍼 줌**: 우클릭으로 3배 줌, 정확도 향상
- **다양한 좀비 타겟**: 3가지 종류의 좀비 (점수 및 크기 차이)
- **실시간 통계**: 반응속도, 명중률, 점수 추적
- **순위 시스템**: 로컬 스토리지 기반 리더보드
- **사운드 효과**: Web Audio API 기반 효과음

## 🕹️ 조작법

- **우클릭**: 스나이퍼 줌 (정확도 증가)
- **좌클릭**: 발사
- **줌 없이 발사**: 정확도가 떨어집니다
- **스페이스바**: 게임 시작 (시작 화면에서)

## 🎯 게임 규칙

1. **라운드 시스템**: 총 10라운드, 각 라운드 60초 제한
2. **난이도 증가**: 라운드가 진행될수록 타겟이 빨라지고 작아짐
3. **타겟 종류**:
   - 🟢 초록 좀비: 15점 (큰 사이즈)
   - 🟠 오렌지 좀비: 25점 (중간 사이즈)
   - 🔴 빨간 좀비: 40점 (작은 사이즈)
4. **보너스 점수**: 높은 라운드에서 추가 점수 획득
5. **줌 효과**: 우클릭 줌 시 정확도 100%, 줌 없이는 40%

## 🏆 점수 시스템

- 타겟별 기본 점수 + 라운드 보너스
- 반응속도 측정 (타겟 출현 후 명중까지 시간)
- 명중률 계산 (총 발사 수 대비 명중 수)
- 상위 10명 리더보드 저장

## 🛠️ 기술 스택

- **HTML5 Canvas**: 게임 렌더링
- **JavaScript ES6+**: 게임 로직
- **CSS3**: UI 스타일링
- **Web Audio API**: 사운드 효과
- **LocalStorage**: 점수 저장

## 📱 호환성

- 모든 모던 브라우저 지원
- 데스크톱 환경 최적화
- 외부 라이브러리 의존성 없음
- 단일 HTML 파일로 배포 가능

## 🚀 실행 방법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 또는 로컬 서버로 실행:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```
3. 브라우저에서 게임 시작

## 🎨 게임 화면

- **시작 화면**: 게임 설명 및 조작법
- **게임 화면**: 
  - 좌측: 타이머, 라운드 정보
  - 우측: 점수, 반응속도, 명중률
  - 하단: 조작법 가이드
- **종료 화면**: 최종 점수 및 리더보드

## 🔧 커스터마이징

게임 설정은 `game.js` 파일에서 수정 가능:

```javascript
// 게임 설정
this.totalRounds = 10;      // 총 라운드 수
this.timeLeft = 60;         // 라운드 시간 (초)
this.maxZoomLevel = 3;      // 최대 줌 배율
this.maxTargets = 3;        // 최대 동시 타겟 수
```
