## 기초 개념

### VLA와 ER

VLA(vision-language-action)는 카메라 영상과 자연어 지시를 받아 로봇 행동을 출력하는 정책이다. ER(embodied reasoning)은 물체, 공간, 도구와 작업 진행 상태를 이해하고 여러 단계의 계획을 세우는 고수준 추론 계층이다. ER이 “무엇을 어떤 순서로 할지”를 정하고 VLA가 “지금 몸을 어떻게 움직일지”를 실행한다.

### 전신 제어

팔만 뻗는 탁상 조작과 달리 전신 제어는 걷기, 쪼그리기, 몸통 기울이기, 양팔과 손가락 조작을 함께 다룬다. 한 관절의 움직임이 무게중심과 접촉력에 영향을 주므로 위치 정확도만이 아니라 균형, 관절 한계, 충돌과 지면 접촉을 동시에 만족해야 한다.

### 자유도와 말단효과기

자유도(DOF)는 독립적으로 움직일 수 있는 축의 수다. 말단효과기(end effector)는 환경과 직접 상호작용하는 손이나 그리퍼다. 발표에서 SharpaWave 손은 22-DOF로 소개되며, 두 손가락 평행 그리퍼보다 가능한 자세가 많지만 제어와 데이터 수집도 더 어렵다.

### 다중 embodiment와 동작 전이

Embodiment는 관절 구조, 센서, 크기와 말단효과기를 포함한 로봇의 물리적 몸이다. 같은 checkpoint가 Apollo 2의 서로 다른 손과 Franka Duo를 다룬다는 설명은 공통 표현을 여러 몸에 적용하려는 방향을 보여 준다. On-Device 2는 새로운 양팔 플랫폼에 보통 200개 미만 예시와 수 시간의 데이터로 적응할 수 있다고 보고하지만, 모든 로봇·작업에 대한 보장은 아니다.

### 폐루프 제어와 성공 추적

실제 환경은 계획대로만 움직이지 않는다. 폐루프 시스템은 `관찰 → 행동 → 새 관찰`을 반복하고, 성공 조건과 실패 사건을 지속적으로 확인한다. ER 2는 작업 시작·종료와 주요 사건의 시점을 판별해 실패한 단계를 다시 시도하거나 계획을 바꾸는 역할을 맡는다.

## 핵심 요약

1. 이전 세대의 상체·탁상 조작 범위를 넘어 걷기, 굽히기, 균형과 양손 조작을 결합한 전신 행동을 다룬다.
2. 고수준 ER과 저수준 VLA를 분리해 수백 번의 결정이 필요한 수 분짜리 작업을 계획하고 실행한다.
3. 다지 손과 평행 그리퍼 모두를 지원하지만, 공개 수치상 다지 조작은 작업별 성공률 편차가 크다.
4. 서로 다른 로봇이 각자의 물리적 강점을 고려해 작업을 분담하는 다중 로봇 협업을 소개한다.
5. On-Device 2는 지연과 연결 문제를 줄이고 새로운 몸체에 적은 시범으로 적응하는 방향을 제시한다.
6. 안전은 의미 판단, 불확실성 처리, 사람 근접 감지, 안전 정지와 전통적 물리 제어를 겹쳐야 한다.

## 상세 정리

### 전신 행동의 의미

발표 시연의 물뿌리개 정리 작업은 단순 pick-and-place가 아니다. 로봇은 테이블까지 이동하고, 물체를 잡고, 선반까지 걸어간 다음 낮은 칸에 몸을 맞춰 배치해야 한다. 팔의 도달 범위를 넘어가면 발 위치와 몸통 자세를 바꿔 작업공간을 확장하면서 무게중심을 지지 다각형 안에 유지해야 한다.

공식 글은 아직 이동 속도를 개선해야 한다고 명시한다. 따라서 “전신 제어 가능”과 “사람과 같은 속도·신뢰성으로 현장 투입 가능”은 구분해야 한다.

### 정교한 손과 그리퍼 제어

다지 손은 매듭 묶기, 지퍼백 닫기, 전구 돌리기처럼 접촉점이 계속 바뀌는 작업에 유리하다. 하지만 22개 자유도, 마찰, 촉각과 가려짐을 함께 다뤄야 해 난도가 높다. 반면 평행 그리퍼는 표현력은 작지만 상태 공간이 단순해 정밀 삽입과 키팅에서 더 안정적일 수 있다.

발표 수치도 이 차이를 보여 준다. 다지 손은 전구 풀기 92%인 반면 조이기 36%, 쓰레기봉투 묶기 44%, 쓰레받기 32%, 지퍼백 40%였다. Franka Duo 그리퍼는 일반 pick-and-place 74.2%, 다양한 도구 키팅 78.9%, 정밀 삽입 89.6%였다. 서로 다른 플랫폼·과제이므로 두 표의 숫자를 직접적인 모델 우열로 해석해서는 안 된다.

### 장기 작업과 자기 수정

ER 2는 방을 관찰하고 작업을 하위 목표로 나누며 VLA에 실행을 맡긴다. 각 단계 후 성공 여부를 추적해 실패하면 재시도하거나 다음 계획을 바꾼다. 이 구조는 open-loop로 긴 action sequence를 한 번에 생성하는 것보다 외란에 대응하기 쉽다.

좋은 오케스트레이터는 단순히 “완료”를 말하는 것이 아니라 증거 기반 종료 조건을 가져야 한다. 예를 들어 물체가 목표 선반 영역에 있고, 손이 물체를 놓았으며, 장애물이 통로를 막지 않는다는 관찰을 함께 확인해야 한다.

### 다중 로봇 협업

다중 로봇 협업에서는 공통 작업을 독립적인 하위 작업으로 나누고, 로봇별 도달 범위·이동성·그리퍼 능력과 현재 위치를 고려해 배정한다. 동시에 같은 공간을 쓰면 경로와 자원 충돌도 조정해야 한다. 통신 실패, 중복 수행과 부분 실패가 발생하므로 중앙 계획 외에 작업 lease, heartbeat, idempotent 명령 같은 분산 시스템 원리도 필요하다.

### 로컬 실행과 빠른 적응

On-Device 2는 네트워크 왕복 지연과 연결 단절을 피하려는 모델이다. 로컬 추론은 반응성과 프라이버시에 유리하지만 계산·전력·열 예산이 제한된다. 새 embodiment 적응에는 관절 표현과 카메라 시점, action space를 정렬한 고품질 시범이 필요하며, “200개 미만”은 발표가 다룬 양팔 플랫폼 조건의 전형적 수치다.

## 공개 평가를 읽는 법

| 범주 | 공개 결과 예시 | 해석 시 주의점 |
| --- | --- | --- |
| Apollo + Inspire 전신 조작 | 테이블 68.4%, 바닥 45.7%, 선반 76.3% | 여러 과제 평균이며 시도 수·환경 분포가 본문에 모두 제시되지 않음 |
| Apollo + Sharpa 다지 손 | 32%~92% | 과제별 난도와 접촉 조건 차이가 매우 큼 |
| Franka Duo 그리퍼 | 74.2%~89.6% | 고정형 양팔과 humanoid 전신 제어는 같은 문제 아님 |
| ER 2 진행 분류 | 57.4% | 비교군보다 높아도 절대 오류율은 여전히 큼 |

평가를 재현하려면 성공 판정 기준, 시험 횟수, 초기 상태 무작위화, 사람 개입, timeout, 속도와 안전 정지 빈도가 필요하다. 성공률 하나만으로 처리량이나 현장 안전성을 판단할 수 없다.

## 안전과 한계

DeepMind는 ASIMOV-Agentic benchmark로 불안전한 VLA tool call 거부, 실행 가능성 예측과 불확실할 때 사람에게 도움을 요청하는 능력을 평가한다고 설명한다. ER 2는 사람 근접 시 안전 도구를 호출하고 정지하도록 설계됐다.

- **의미 안전**: 위험한 목표·도구 호출 거부, 작업 가능성 판단
- **계획 안전**: 금지 구역, 동시 작업 충돌, human approval gate
- **동작 안전**: 관절·속도·힘·무게중심·self-collision 제한
- **독립 안전 장치**: 비상 정지, 안전 PLC, 거리 센서와 전원 차단
- **운영 안전**: 작업구역 관리, 로그, 권한, 점검과 사고 대응

알려진 또는 공개 자료에서 드러나는 제한은 느린 움직임, 다지 조작의 불균일한 성공률, private-preview 중심의 제한된 접근성이다. 영상 시연은 긴 꼬리 상황, 마모, 조명 변화, 센서 고장과 사람의 예측 불가능한 행동을 충분히 대표하지 않는다.

## 용어 정리

| 용어 | 설명 |
| --- | --- |
| Physical AI | 물리 환경을 인지하고 실제 장치로 행동하는 AI |
| VLA | vision-language-action; 영상·언어를 로봇 행동으로 연결하는 모델 |
| ER | embodied reasoning; 물리 공간과 행동 결과를 고려하는 체화 추론 |
| Whole-body control | 보행, 균형, 몸통, 팔과 손을 함께 조정하는 제어 |
| DOF | degree of freedom; 독립적으로 움직일 수 있는 축의 수 |
| End effector | 손, 그리퍼처럼 환경과 직접 접촉하는 말단 장치 |
| Embodiment | 로봇의 형태, 관절, 센서와 action space를 아우르는 몸체 |
| Motion transfer | 한 로봇에서 배운 동작 표현을 다른 몸체에 옮기는 기술 |
| Closed loop | 실행 결과를 다시 관찰해 다음 행동을 수정하는 제어 방식 |
| Safety shield | 학습 정책의 행동을 물리 제약으로 검사·수정·거부하는 계층 |

## 실습 학습 가이드

- [01_foundations.ipynb](01_foundations.ipynb): 2링크 팔의 순기구학과 전신 reachability를 계산한다.
- [02_practice.ipynb](02_practice.ipynb): ER 계획을 상태 기계로 실행하고 실패 후 재계획한다.
- [03_advanced.ipynb](03_advanced.ipynb): 여러 로봇의 능력에 따라 작업을 배정하고 안전 shield를 적용한다.

노트북은 Python 3 표준 라이브러리만 사용한다. 이는 Gemini Robotics 모델 자체를 실행하거나 원 발표 성능을 재현하는 코드가 아니라, 공개 설명의 핵심 시스템 개념을 작은 시뮬레이션으로 학습하는 toy exercise다.
