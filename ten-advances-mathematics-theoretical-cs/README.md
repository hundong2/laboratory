## 한눈에 보기

OpenAI는 아직 공개되지 않은 내부 모델 **Astra**가 최소 10년 이상 핵심 진전이 없었던 문제들에서 10개 결과를 만들었다고 발표했다. 분야는 고차원 기하, 부호 이론, 군론, 작용소 대수, 산술 회로 복잡도, 양자 복잡도, 격자 암호와 극값 조합론에 걸친다.

발표가 설명하는 산출 과정은 다음과 같다.

```text
공개 연구 문제 평가
  → Astra가 수학적 논증 탐색
  → 인간이 같은 모델을 사용해 원고 작성·정리
  → 모델이 각 논증을 Lean 4로 형식화
  → 논문·발견 과정 해설·Lean 인증 공개
  → 수학 공동체의 독립 검토
```

OpenAI는 해를 찾는 데 사용된 전체 token 비용이 Sol API 요금 기준 약 2,000달러라고 추산한다. 이는 연구자의 문제 선정, 평가 기반, 원고 검수, 형식화와 외부 검토 비용을 모두 포함한 “발견 총비용”이 아니다.

## 기초 개념

### 정리, 증명과 인증서

정리(theorem)는 가정에서 결론이 따라온다는 주장이고, 증명은 그 연결을 설명하는 논증이다. Lean 인증서는 정의와 보조정리를 명시한 형식 언어를 작은 trusted kernel이 검사한 결과다. 형식 검증은 전사된 명제에서 논리적 빈틈을 줄이지만, 그 명제가 원래 연구 질문을 정확히 표현했는지와 중요한 맥락이 빠지지 않았는지는 여전히 사람이 확인해야 한다.

### 점근 경계

고차원 또는 큰 입력에서 정확한 값 대신 증가·감소 속도를 비교한다. `O(f(n))`은 상한, `Ω(f(n))`은 하한, `Θ(f(n))`은 같은 차수의 양방향 경계를 뜻한다. 지수의 작은 개선은 차원이 커질수록 큰 비율 차이를 만든다.

### 구성적 결과와 비구성적 결과

어떤 대상이 존재함을 보이는 것과 실제 대상을 명시적으로 만드는 것은 다르다. 비소픽 군 결과는 명시적 구성을, Ramsey 하한은 특정 크기의 나쁜 구조가 존재하도록 하는 확률적·조합적 구성을 다룬다.

### 계산 복잡도와 hardness

복잡도 하한은 문제를 계산하는 모든 허용 알고리즘·회로가 최소 얼마의 자원을 써야 하는지 말한다. 근사 hardness는 일정 비율보다 더 좋은 근사가 가능하다면 널리 믿는 복잡도 가정이 무너지는 식의 reduction으로 표현된다.

## 10개 결과

### 1. 고차원 구 채우기

같은 반지름의 구를 `R^d`에 얼마나 조밀하게 넣을 수 있는지를 묻는다. 논문은 Cohn–Elkies 선형 계획법의 점근적 세기를 정확히 결정하고, 일반 차원의 밀도 상한 지수를 1978년 이후 처음 개선했다고 주장한다. 새 지수는 약 `0.6044`이며 이 선형 계획 틀 자체가 더 나은 지수를 낼 수 없는 문턱도 함께 제시한다.

### 2. 이진·구면 부호

부호어 사이 최소 거리를 고정했을 때 가능한 최대 개수를 묻는다. 모든 prescribed minimum distance에서 고전적 이진 부호 상한을 지수 인자만큼 개선하고, 고차원 구면 부호에도 대응하는 결과를 제시한다. 통신 신뢰성과 sphere packing을 연결하는 공통 거리 기하가 핵심이다.

### 3. 비소픽 군

소픽 군은 유한 순열로 국소적 곱셈 구조를 근사할 수 있는 가산 군이다. 모든 가산 군이 소픽인지 오랫동안 알려지지 않았다. 논문은 property-(T) expander와 binary Leavitt algebra를 사용해 명시적인 비소픽 군을 구성한다고 주장한다.

### 4. Connes 강성 추측

특정 property-(T) 군이 그 군 von Neumann 대수에 의해 유일하게 결정되는지를 묻는다. 동일한 군 von Neumann 대수를 가지지만 서로 동형이 아닌 군을 무한히 많이 구성해 추측을 반증하고, Popa의 관련 finite-to-one 질문에도 답한다고 설명한다.

### 5. 산술 회로 복잡도

행렬 permanent는 determinant와 비슷하지만 순열 항의 부호가 모두 양수여서 계산이 훨씬 어렵다. 논문은 division-free 산술 회로에 `Ω(n² log log n)` gate, 산술 formula에 `Ω(n⁴/log n)` leaf가 필요하다는 새로운 하한을 제시한다. formula는 중간 결과 공유가 없는 tree라 circuit보다 제한적이다.

### 6. 양자 병렬 반복

게임을 여러 번 독립 반복하면 모든 게임에서 이길 확률이 지수적으로 감소하는지 묻는다. 유한한 모든 2인 entangled game에 대해 지수적 parallel-repetition theorem을 제시해 고전 복잡도 이론의 원리를 기존 특수 양자 게임 너머로 확장한다.

### 7. 최단 벡터 문제

CVP(Closest Vector Problem)는 주어진 target에 가장 가까운 격자점을 찾는다. 3SAT에서 직접 reduction하여 Euclidean CVP를 `n^(1/400)` 인자 안으로 근사하는 문제의 hardness를 보이고, binary decoding과 다른 격자 norm에도 결과를 연결한다. 격자 문제는 post-quantum cryptography의 안전성 분석과 밀접하다.

### 8. Ehrhart 부피 추측

무게중심이 유일한 내부 격자점인 `n`차원 convex body의 최대 부피를 묻는다. 모든 차원에서 sharp bound `(n+1)^n / n!`을 증명한다고 주장한다. 격자점이라는 이산 조건과 convex volume이라는 연속량을 연결한다.

### 9. 다색 Ramsey 수

완전 그래프의 edge를 `k`색으로 칠할 때 단색 삼각형을 반드시 만드는 최소 vertex 수 `R_k(3)`을 다룬다. 초지수 하한으로 `R_k(3)=k^{Θ(k)}`를 확립해 Erdős problem 183을 해결한다고 설명한다.

### 10. 극값 그래프의 compactness와 degeneracy

특정 작은 graph를 피하면서 얼마나 많은 edge를 가질 수 있는지에 관한 두 추측을 별도의 bipartite graph 구성으로 반증한다. 각각 Erdős–Simonovits compactness conjecture와 Erdős의 degeneracy conjecture에 대응하며 Erdős problem 146과 180을 해결한다.

## 발견부터 검증까지

### 발견 과정 해설의 역할

별도 해설은 완성된 증명을 반복하기보다 어떤 관점이 길을 열었고 어떤 접근이 막혔는지 재구성한다. 예를 들어 sphere packing에서는 전역 norm 부등식만 개선하려는 길이 필요한 위치 정보를 잃는다는 장애를 확인한 뒤, 음의 질량이 놓이는 반지름을 직접 제어하는 국소 부등식과 Mellin 변환 관점으로 전환한다.

이 자료는 모델이 원래 생성한 raw chain-of-thought 그 자체가 아니라, 원래 추론 기록과 완성 논문을 읽은 모델이 작성한 고수준 서술이다. 따라서 “발견 과정 해설”과 “원시 내부 사고 기록”을 구분해야 한다.

### Lean 인증의 역할

공개 저장소에는 10개 주제에 대응하는 Lean 파일과 통합 `All.lean`이 있다. Lean kernel은 정의된 명제와 공리 아래에서 proof term을 검사한다. 검증해야 할 층은 다음처럼 나뉜다.

1. 자연어 연구 문제가 Lean 명제로 정확히 옮겨졌는가?
2. 필요한 가정이 빠지거나 지나치게 강해지지 않았는가?
3. Lean kernel이 proof term을 받아들이는가?
4. 자연어 논문이 형식 증명과 같은 논증을 전달하는가?
5. 결과가 선행 연구 대비 실제로 새롭고 중요한가?

### 저자 표시와 책임

OpenAI는 AI가 전적으로 생성한 증명을 인간 저자의 지적 작업으로 표시하면 생산 과정을 잘못 표현한다고 말한다. 발표는 수학적 논증은 시스템이 생성했고, 인간은 원고 준비와 형식화를 도왔으며 OpenAI가 정확성에 책임을 진다고 구분한다. 장기적으로는 기여 기록, 재현 가능한 실행 기록, 검토 책임과 학술 credit 규칙이 함께 발전해야 한다.

## 해석할 때 주의할 점

- 발표와 논문·Lean 파일이 공개됐다는 사실은 동료 평가와 독립 검증이 완료됐다는 뜻이 아니다.
- 형식 증명은 formal statement의 논리적 정확성을 검사하지만 연구 질문과의 의미 대응은 별도 검토 대상이다.
- 10개 결과의 난도와 형태는 서로 달라 하나의 benchmark 점수처럼 평균낼 수 없다.
- “약 2,000달러”는 특정 API 가격으로 환산한 token 비용이며 전체 연구비나 재현 비용이 아니다.
- Astra는 발표 시점에 공개되지 않은 내부 모델이므로 외부 연구자가 같은 탐색 절차를 그대로 재현할 수 없다.
- reasoning walkthrough는 교육적으로 유용하지만 사후 재구성된 설명이다.

| --- | --- |
| Sphere packing | 겹치지 않는 동일 구를 공간에 최대 밀도로 배치하는 문제 |
