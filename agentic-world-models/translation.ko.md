## 에이전트형 세계 모델

강화학습은 LLM 에이전트의 능력 확장에 중요한 역할을 했지만 학습 신호가 희소하다는 한계가 있다. 대부분의 에이전트는 전체 궤적이 성공했는지를 나타내는 단일 결과 보상으로 학습한다. 과정 보상을 추가해 일부 완화할 수 있지만 감독 희소성과 샘플 비효율 문제는 남는다.

반면 에이전트 궤적 자체는 정보가 풍부하다. 매 상호작용에는 에이전트의 행동과 그 결과인 환경 관찰이 함께 있어 환경이 행동에 어떻게 반응하는지를 보여준다. 표준 에이전트 RL은 관찰 토큰을 손실에서 제외하지만, 최근 연구는 에이전트가 다음 관찰을 예측하도록 학습하면 조밀한 감독 신호로 사용할 수 있음을 보인다. 정확한 내부 세계 모델은 학습 효율, 능력과 일반화를 개선할 수 있다.

## 에이전트에서 세계 모델로

### 지도 미세조정

지도학습은 텍스트 시퀀스의 각 위치에서 실제 다음 토큰을 맞히도록 cross-entropy 손실을 적용한다. 프리트레이닝과 SFT는 같은 다음 토큰 예측 목표를 쓰지만 역할이 다르다. 프리트레이닝은 방대한 원시 텍스트로 넓은 지식 기반을 만들고, SFT는 적은 양의 선별·합성 데이터로 스타일, 선호와 지시 이행을 다듬어 RL의 출발점을 만든다.

### 강화학습과 GRPO

강화학습은 모델이 생성한 출력에 보상을 주어 더 나은 행동 확률을 높인다. GRPO는 같은 질문에 대한 출력 그룹에서 상대적 advantage를 계산하고 PPO와 유사한 중요도 비율·clipping을 사용한다. 결과 보상은 전체 실행에 한 번만 주어질 수 있어 긴 궤적에서 세부 행동에 대한 학습 신호가 희박하다.

### 에이전트형 RL

에이전트 시스템은 LLM을 다음 기능을 가진 harness로 감싼다.

- 문제 해결 지시와 사용 가능한 도구 제공
- 도구 호출 파싱과 실행
- 도구 출력·환경 관찰을 모델에 반환
- 모델이 볼 문맥 관리
- 다단계 문제를 풀도록 반복 실행

일반적으로 프롬프트와 환경 토큰은 RL 손실에서 가리고 에이전트가 생성한 행동 토큰만 학습한다. 이 action masking은 환경 관찰을 다음 행동의 문맥으로는 쓰지만 직접 감독 신호로는 쓰지 않는다.

### LLM 에이전트를 위한 세계 모델링

유효한 문장을 생성하는 능력만으로 외부 세계의 역학을 이해했다고 볼 수 없다. “비행기표가 예약됐다”고 말하는 것과 실제 API를 호출해 데이터베이스에서 예약을 확인하는 것은 다르다.

세계 모델은 외부 환경의 세부 상태와 변화를 모델링한다. MDP에서 환경 상태는 세계의 완전한 표현이지만 에이전트는 보통 도구 출력이나 영상 프레임 같은 부분 관찰만 받는다. 에이전트 분야의 언어 세계 모델은 이전 궤적과 행동을 조건으로 다음 도구 출력이나 관찰을 예측한다.

두 가지 주요 방식이 있다.

1. 관찰 예측만 담당하는 별도 세계 모델
2. 행동하는 정책이면서 그 행동 결과도 예측하는 통합 LLM

통합 방식은 행동 토큰에 RL을, 관찰 토큰에 지도학습을 적용하는 혼합 목표를 사용한다.

## 에이전트에게 세계 모델 가르치기

### ECHO: 터미널 에이전트는 세계 모델을 무료로 배운다

터미널 에이전트는 명령을 출력하고 환경은 stdout, stderr, 파일, 로그와 종료 코드를 돌려준다. ECHO는 최대 16회의 환경 상호작용을 수행하는 terminal task에서 이 반환값을 관찰 예측의 정답으로 사용한다.

모든 실험은 같은 GRPO 방법을 사용하며 Qwen3-8B, Qwen3-14B와 expert trajectory로 SFT된 OpenThinker-Agent 계열 시작 정책을 비교한다. ECHO는 모든 시작 정책과 평가에서 순수 GRPO보다 높은 성능을 보였다. 논문은 TerminalBench-2.0에서 Qwen3 모델의 pass rate가 약 두 배가 됐다고 보고한다. 8B 설정에서는 순수 GRPO의 최고 성능에 1.5~2.3배 적은 단계로 도달했다. timeout 비율과 완성 토큰 수도 감소해 추론 예산을 더 효율적으로 쓰는 경향을 보였다.

### True Agents Model the World

프리트레이닝은 관찰 데이터를 예측하는 simulator를 만들고, RL은 모델 자신의 생성 행동을 보상으로 개선한다. 에이전트는 두 방식으로 동시에 배워야 한다. 세계 모델링 중 관찰은 현재 정책 행동이 실제로 유발한 결과이므로 on-policy 학습 신호다.

분석은 모든 도구 출력을 학습하는 ECHO(all)과 코드 실행 출력만 학습하는 ECHO(code)를 비교한다. `forth-lang`에서는 코드 출력만 사용했을 때 더 좋은 결과가 나왔다. 문서 검색 결과는 환경 역학보다 지식을 암기하게 만들 위험이 있기 때문이다. 다만 다른 환경에서는 모든 도구 출력이 유용할 수 있어 선택은 과제에 따라 달라진다.

세계 모델링 전용 학습은 관찰 perplexity를 낮춰도 과제 성능을 최적으로 만들지 못했다. 가장 좋은 결과는 RL과 관찰 예측을 함께 사용했을 때 나왔다. 훈련 도메인 성능은 일관되게 좋아졌지만 다른 도메인 일반화는 학습된 도구 사용 습관과 대상 환경의 유사성에 따라 달랐다.

### 정책과 세계 모델 공동 학습(PaW)

PaW도 rollout에 이미 존재하는 행동-다음 관찰 쌍을 사용한다. 정책 갱신 외에 다음 관찰을 맞히는 세계 모델 손실을 같은 모델에 적용한다. 추가 rollout, 별도 모델이나 별도 학습 단계가 필요하지 않으며 추론 방식도 표준 에이전트와 같다.

PaW는 관찰 신호가 유익하고 안정적으로 작동하도록 행동 entropy 기반 데이터 선택, 잡음에 강한 손실과 reward 적응형 보조 손실 가중치를 도입한다. 관찰이 너무 쉽게 예측되거나 reward가 낮은 그룹에서는 세계 모델 손실의 영향을 조절한다.

### Qwen-AgentWorld: 범용 에이전트를 위한 언어 세계 모델

Qwen-AgentWorld는 별도의 텍스트 기반 simulator를 학습한다. MCP 서버, 검색, 터미널, 소프트웨어 엔지니어링과 웹·Android·데스크톱 GUI 환경을 포함한다. GUI는 렌더링 가능한 코드로 표현해 세계 모델링을 텍스트 문제로 통일한다.

system message에는 시뮬레이션 목적, 행동 공간, 초기 상태, 선택적 예시와 출력 제어 지시가 들어간다. 그 뒤 행동-관찰 상호작용 이력과 마지막 행동을 주고 다음 관찰을 예측하게 한다.

훈련 데이터는 전용 환경 backend, 공개 데이터와 사내 궤적에서 모은다. 너무 짧은 궤적, 치명적 환경 실패, 행동 공간 밖의 도구 호출, 빈 turn, 반복 오류와 GUI 무변화 turn을 필터링한다.

훈련은 다음 세 단계다.

- **CPT**: 환경 궤적과 법률·의료·금융·제조·보안 같은 세계 지식으로 일반 역학을 학습한다.
- **SFT**: 다음 관찰 전 reasoning trace를 생성하도록 하고 다양한 prompt template로 일반화를 높인다.
- **RL**: 관찰 품질 rubric과 규칙 보상으로 simulator fidelity를 높인다.

AgentWorldBench는 여러 실제 에이전트 benchmark에서 나온 2,170개 궤적으로 언어 세계 모델의 관찰 시뮬레이션 품질을 평가한다. 비교 대상 범용 모델은 세계 모델링에 특화되지 않았다는 점을 함께 고려해야 한다.

별도 세계 모델은 실제 환경을 대신해 RL rollout을 생성할 수 있다. 이 SimRL 방식에서 세계 모델 품질은 중요했으며, 일반 LLM으로 simulator를 대체했을 때는 정책 개선이 나타나지 않았다. API 오류, 페이지네이션과 부분 실패를 주입하는 제어 지시도 효과적인 학습에 필요했다.

## 중요한 결론

### 세계 모델링은 보조 학습 목표다

RL은 높은 보상을 얻는 행동을, 세계 모델링은 그 행동에 대한 환경 반응을 가르친다. 두 목표를 함께 최적화하면 샘플 효율, 에이전트 성능과 일부 일반화를 개선할 수 있다. 세계 모델 정확도만 최대화하는 것은 목표가 아니다.

### 환경 관찰은 감독 신호다

표준 RL에서 버려지는 관찰은 실패한 궤적에서도 행동 결과를 설명한다. 그러나 반복 실패, 무효 도구 호출, 정보가 적은 관찰은 걸러야 한다. 모든 관찰 토큰이 같은 교육 가치를 갖지는 않는다.

### 과적합을 주의해야 한다

세계 모델 손실은 매 단계 조밀한 피드백을 주므로 순수 RL보다 빨리 과적합할 수 있다. 특히 검색 중심 환경에서는 환경 역학 대신 검색 내용을 암기할 위험이 있다. 해결책은 보조 손실 가중치 조절, 목적함수별 정규화, 데이터·도구 선택과 early stopping이다. 훈련 보상이 갑자기 오르면서 held-out 점수가 급락하면 과적합 신호일 수 있다.

### 비용과 확장성

통합형 세계 모델링은 기존 rollout과 log probability를 재사용하므로 비교적 작은 변경으로 구현할 수 있다. 별도 simulator는 구축 비용이 들지만 실제 환경 인프라 의존을 줄이고 제어된 실패를 대규모로 생성할 수 있다.

### 에이전트 능력

원문이 검토한 결과에서 세계 모델링을 포함한 에이전트는 도구를 더 효과적으로 사용하고, 더 적은 전문가 시범으로 학습하며, 추론 예산을 효율적으로 쓰고, 일부 낯선 환경에 더 잘 일반화했다. 다만 환경과 목표 설정에 따라 음의 전이와 과적합이 나타날 수 있다.
