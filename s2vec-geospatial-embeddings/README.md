## 한눈에 보기

S2Vec는 도시와 지역의 "건조 환경"을 숫자 벡터로 바꾸는 자기지도 학습 프레임워크입니다. 건조 환경은 도로, 상점, 주거지, 공원, 교통 시설처럼 사람이 만든 공간 구조를 뜻합니다.

핵심 발상은 다음과 같습니다.

- 지구 표면을 S2 Geometry 셀로 나눈다.
- 각 작은 셀에 POI 카테고리와 도로/교통 피처의 개수 히스토그램을 만든다.
- 작은 셀들을 큰 셀 안의 16x16 패치 이미지처럼 배열한다.
- 일부 패치를 가리고 복원하는 Masked Autoencoding(MAE)으로 공간 패턴을 학습한다.
- 학습된 패치 인코더의 출력을 특정 위치의 범용 지리공간 임베딩으로 사용한다.

논문은 S2Vec가 인구 밀도, 중위 소득, 주택 가격 같은 사회경제 예측에서 이미지 기반 임베딩과 경쟁력 있는 성능을 보이고, 특히 보지 못한 지역으로 일반화하는 zero-shot geographic adaptation에서 강점을 보인다고 보고합니다. 반면 나무 피복률과 고도 같은 환경 과제에서는 위성 이미지 기반 임베딩이 더 강했습니다.

## 기초 개념

**지리공간 임베딩**은 좌표, 도로, 건물, POI, 위성 이미지 같은 공간 정보를 머신러닝 모델이 쓰기 좋은 고정 길이 벡터로 바꾼 표현입니다. 좋은 임베딩은 단순 위치뿐 아니라 주변 맥락과 지역의 기능적 성격을 담아야 합니다.

**S2 Geometry**는 지구 표면을 평면 지도 투영이 아니라 구면 위의 계층적 셀로 다루는 라이브러리입니다. 논문은 S2 level 12 셀을 약 5 km2 단위의 패치로, S2 level 8 셀을 약 1300 km2 단위의 부모 이미지로 사용합니다. level 8 부모 셀 하나는 level 12 자식 셀을 16x16 패치로 포함합니다.

**건조 환경 피처 벡터**는 각 셀 안에 있는 POI 카테고리, 도로, 교통 시설 등을 세어 만든 히스토그램입니다. 논문 실험의 벡터 차원은 116이며, 내부 Google Maps 데이터에서 추출되었습니다.

**래스터화**는 각 셀의 피처 벡터를 이미지 패치처럼 일정한 2D 순서로 배열하는 과정입니다. 이렇게 하면 지도 데이터를 컴퓨터 비전 모델이 처리하는 이미지와 비슷한 텐서로 만들 수 있습니다.

**Masked Autoencoding**은 입력의 일부 패치를 숨긴 뒤 나머지 맥락으로 숨긴 패치를 복원하도록 학습하는 자기지도 방식입니다. 라벨 없이도 "어떤 지역 패턴에서는 어떤 피처가 함께 나타나는가"를 학습할 수 있습니다.

**Zero-shot geographic adaptation**은 학습에 쓰지 않은 지역 전체를 테스트로 남겨두고, 모델이 새로운 지리권역에 일반화되는지 보는 평가입니다. 무작위 분할보다 실제 배포 상황에 더 가깝습니다.

## 핵심 요약

S2Vec의 목적은 특정 과제에 맞춘 수작업 피처를 매번 만들지 않고, 여러 GeoAI 예측 과제에 재사용 가능한 건조 환경 표현을 학습하는 것입니다.

파이프라인은 `S2 셀 분할 -> 셀별 피처 카운트 -> 16x16 피처 이미지 -> MAE 사전학습 -> 패치 임베딩 -> 다운스트림 회귀` 순서로 진행됩니다.

논문 실험에서는 256차원 임베딩을 사용했습니다. MAE는 8개 attention head, 6개 encoder layer, 2개 decoder layer, mask ratio 0.5, AdamW optimizer로 학습되었습니다.

다운스트림 평가는 California 주택 가격, 미국 전체 인구 밀도, 미국 전체 중위 소득, 미국 전체 tree cover, 미국 전체 elevation 과제로 구성됩니다. 모델은 임베딩 위에 2-layer MLP를 얹어 회귀를 수행합니다.

결과적으로 S2Vec는 사회경제 과제에서는 강하지만, 환경 과제처럼 식생, 지형, 물리적 표면 특성이 직접 중요한 경우에는 위성 이미지 임베딩보다 약합니다. 논문은 S2Vec와 이미지 기반 임베딩을 결합하면 많은 경우 단일 모달보다 성능이 좋아진다고 보고합니다.

## 상세 정리

### 1. 왜 좌표만으로 부족한가

좌표는 위치를 알려주지만, 그 위치가 어떤 생활권인지 직접 말해주지 않습니다. 같은 위도/경도 근처라도 고속도로, 상업지, 주거 밀도, 대중교통 접근성에 따라 인구 밀도나 소득 예측 신호가 달라집니다. S2Vec는 좌표 자체보다 "그 좌표 주변에 무엇이 어떻게 분포하는가"를 학습합니다.

### 2. 피처 벡터 설계

논문은 각 S2 level 12 셀에 대해 POI 카테고리와 도로/교통 인프라 개수를 세어 116차원 히스토그램을 만듭니다. 이 선택은 단순하지만 의도적입니다. 복잡한 수작업 가중치를 먼저 넣으면 성능이 피처 엔지니어링 때문인지 MAE 학습 때문인지 분리하기 어렵기 때문입니다.

다만 단순 카운트는 한계가 있습니다. 대형 쇼핑몰과 작은 상점 하나를 같은 카운트로 취급하고, 도로망의 연결성이나 품질도 세밀하게 담지 못합니다. 이 한계는 논문에서도 향후 과제로 명시됩니다.

### 3. 래스터화의 의미

각 level 8 부모 셀은 16x16개의 level 12 자식 셀을 포함합니다. 각 자식 셀의 116차원 피처 벡터를 패치로 보면, 부모 셀은 `16 x 16 x 116` 형태의 이미지가 됩니다. 행 우선(row-by-row)으로 일관되게 배열하면 모델의 위치 임베딩이 실제 지리적 인접성을 학습할 수 있습니다.

이 단계가 중요합니다. 셀들의 순서가 임의로 섞이면 같은 피처 개수라도 도시 중심부에서 교외로 이어지는 공간 문법이 사라집니다.

### 4. MAE로 배우는 표현

S2Vec의 MAE는 일부 패치를 랜덤하게 제거하고, 남은 패치의 맥락으로 숨겨진 피처를 복원합니다. 학습 후에는 전체 이미지 표현이 아니라 각 패치의 encoder 출력이 위치별 임베딩으로 쓰입니다.

이 방식은 두 가지 신호를 동시에 담습니다.

- 해당 셀 자체의 기능적 조성: 예를 들어 음식점, 상점, 도로, 대중교통 피처 수
- 주변 패턴: 예를 들어 도심부에서 상업/교통 피처가 함께 증가하고, 외곽으로 갈수록 주거/녹지 비중이 커지는 구조

### 5. 이미지 임베딩과의 결합

S2Vec는 지도 데이터베이스 기반 모달리티입니다. 위성 이미지, 거리 이미지, 이동 데이터와는 다른 정보를 제공합니다. 논문은 S2Vec와 SATCLIP, GEOCLIP, RS-MaMMUT 같은 이미지 기반 임베딩을 결합해 보았습니다.

결합 방식은 세 가지입니다.

- Concatenation: 두 벡터를 그대로 이어 붙임
- Weighted addition: 같은 차원의 두 벡터에 학습 가능한 가중치를 곱해 더함
- Projection and addition: 각 벡터를 같은 차원으로 투영한 뒤 더함

논문에서는 project-then-add가 여러 설정에서 수치적으로 가장 좋은 결합 방식으로 나타났습니다.

### 6. 평가 결과 해석

무작위 train/validation/test 분할에서는 이미지 기반 임베딩이 강한 경우가 많았습니다. 미국 인구 밀도에서는 RS-MaMMUT가 가장 낮은 MAE를 냈고, 중위 소득에서는 GEOCLIP가 가장 강했습니다. S2Vec는 사회경제 과제에서 경쟁력 있는 단일 모달 성능을 보였고, 결합 모델은 대체로 단일 모달을 보완했습니다.

Zero-shot geographic adaptation에서는 S2Vec의 장점이 더 분명해졌습니다. 미국의 특정 하위 지역을 통째로 테스트로 빼는 설정에서 S2Vec는 SATCLIP과 GEOCLIP 단일 모델보다 강했고, 인구 밀도에서는 RS-MaMMUT와 결합한 S2-RS가 가장 높았습니다. 중위 소득에서는 S2Vec가 가장 강한 단일 모달이었고, S2-GEOCLIP 결합이 전체 최고 성능을 냈습니다.

환경 과제에서는 반대 양상이 나옵니다. Tree cover와 elevation은 건조 환경 카운트보다 위성 이미지가 직접적인 관측 신호를 담습니다. 따라서 S2Vec 단독은 이미지 임베딩보다 약했고, 결합은 S2Vec 단독보다 개선되지만 이미지 단독을 항상 넘지는 못했습니다.

### 7. 실무 적용 시 주의점

S2Vec를 실제 프로젝트에 적용하려면 먼저 사용할 지도 데이터의 품질, 최신성, 지역별 커버리지 편향을 점검해야 합니다. POI가 덜 등록된 지역은 "활동이 적은 지역"이 아니라 "지도 데이터가 부족한 지역"일 수 있습니다.

또한 평가 분할을 무작위로만 하면 모델이 주변 지역 패턴을 외운 것인지, 완전히 새로운 지역에 일반화되는지 알기 어렵습니다. 지역 단위 holdout, 시간 단위 holdout, 데이터 출처 단위 holdout을 함께 설계해야 합니다.

## 용어 정리

| 용어 | 의미 |
| --- | --- |
| GeoAI | 지리공간 데이터를 대상으로 하는 인공지능 및 머신러닝 분야 |
| Built environment | 도로, 건물, 상점, 교통 시설처럼 사람이 만든 물리적 환경 |
| S2 cell | S2 Geometry가 지구 표면을 계층적으로 나눈 셀 |
| Patch cell | S2Vec에서 위치별 임베딩을 얻는 작은 셀, 논문 실험에서는 level 12 |
| Image cell | 여러 patch cell을 2D 이미지처럼 묶는 부모 셀, 논문 실험에서는 level 8 |
| Feature vector | 각 셀의 POI/도로/교통 피처 카운트 히스토그램 |
| Rasterization | 벡터/지도 데이터를 격자 이미지 형태로 배열하는 과정 |
| MAE | 입력 일부를 가리고 복원하도록 학습하는 Masked Autoencoding |
| Embedding | 복잡한 입력을 고정 길이 숫자 벡터로 압축한 표현 |
| Multimodal fusion | 서로 다른 모달리티의 임베딩을 결합하는 방법 |
| Geographic adaptation | 학습하지 않은 지역에 모델이 일반화되는지 보는 평가 |
| Mean Absolute Error | 예측값과 실제값 차이의 절댓값 평균. Masked Autoencoding의 약자 MAE와 표기가 겹치므로 문맥을 구분해야 함 |
